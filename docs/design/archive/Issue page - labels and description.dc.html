Notes and gaps

Behaviour

  • Label picker: Enter or Space on the Labels row opens it with focus in the filter field. ↑ and ↓ move the highlight; Enter toggles the highlighted label and saves straight away; the picker stays open for more changes. Escape closes it and returns focus to the Labels row. Each toggle is its own save, so last save wins (STD-8).
  • Labels are listed alphabetically, ignoring capitals. The Labels row shows a change only after the server accepts it; on a failure it keeps the old labels and the toast shows for 5 s.
  • “Create label …” appears only when the filter matches no label, ignoring capitals. Enter on it creates the label as Gray and adds it. Typing “design” finds Design, so nothing is created (REQ-020.5).
  • At 10 labels, choosing another shows “Maximum 10 labels” under the row and saves nothing. Removing a label still works and clears the error.
  • Race (REQ-020.4): Sam added docs, then chose frontend as Alex deleted it. Docs stays; frontend disappears from the list.
  • Description: Edit swaps the formatted view for the Markdown text area with focus at the end. Save submits; Escape or Cancel discards and returns to the view (Escape first closes the suggestion list if it’s open). Empty saves are allowed.
  • Conflict (STD-8): nothing is saved, the text stays, and Save stays enabled. The message sits in the editor bar and is announced.
  • Rendering (SEC-002, DATA-001): raw HTML shows as text; links are http, https or mailto only and open in a new tab. Only @username of an active member outside code becomes a mention; @nobody, deactivated members, sam@acme.com and foo@sam stay plain. Mentions inside (@sam) or before a comma still count.

Missing from the kit

  • A multi-select picker. Composed here from Pick, Pop, PopSearch and PopItem; the ✓ on PopItem means “on this issue”. Pick’s open state (tint-2 fill) is improvised, as on the Issue page.
  • Label colour tokens for the eight spec colours. Every label is the neutral label pill.
  • A task-list style in Prose. Drawn with the Checkbox box, read-only, in the serif.
  • A mention tooltip trigger. Drawn with Tip in its wrapper; Mention isn’t focusable, so keyboard users can’t reach the name. Needs a decision.
  • A mention suggestion list. Composed from Pop and PopItem with Avatar; the highlight is PopItem’s selected fill without ✓, plus the focus ring. It needs caret-position anchoring, which Pop doesn’t do.
  • A Markdown editor state for Editor: no invalid style (the terracotta ring is borrowed from Input) and no room for an inline message in its bar. Editor’s textarea is serif; Markdown source is shown in mono here.
  • A toast without dismiss and with a 5 s timeout. Same gap as earlier screens.
