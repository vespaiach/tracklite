Notes and gaps

  • Hover shows the full date and time through the native title on each time. The kit has no tooltip component; a keyboard-reachable tooltip is needed so focus users get the same detail.
  • Worker down: the spec gives no threshold for “down”, so “12 min ago” is shown plainly. If a threshold is defined, a terracotta Tag (accent-2) beside the time is the kit’s exception treatment.
  • Recent problems has no state column (failed or bounced), per the listed columns. Add one if admins need to tell them apart.
  • With more than 20 problems the table shows no “showing 20 of 25” line; the spec gives no copy for it.
  • Oldest due wait shows “None” when nothing is due; the spec gives no copy for that case.
  • Refresh reloads the whole page’s data once; numbers stay visible and the button reads “Refreshing…” while disabled. Nothing polls. A failed refresh is not specified; suggest the STD-9 toast “Couldn’t load this.” with the old numbers kept.
  • Missing from the kit: loading indicator, Button busy state, stat/definition-list row (drawn with table-style 1px rules).
  • No email addresses or notification text anywhere (SEC-007): recipients are usernames only.
