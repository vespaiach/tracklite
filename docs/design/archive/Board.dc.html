Notes and gaps

  • Move to submenu: the current status stays in the list, marked ✓ and disabled, so the five statuses always read in the same order. Move to top is disabled when the card is already first, and Move to bottom when it is last.
  • Done and Canceled counts only include issues moved there in the last 14 days, matching the cards shown. Their empty state reads “Nothing moved here in the last 14 days.”
  • Empty open columns read “No issues yet. Create one.” The link does the same as that column’s +. In an archived project they read “No issues.” with no link.
  • Card: the title is the link that opens the issue, and its hit area covers the whole card. The drag handle and ⋯ sit above it in tab order: handle, title, ⋯. Title is cut off after 2 lines; the full title shows on the issue page.
  • Mouse drag: the source card leaves its column, and counts change on drop. If the move fails, the card returns to where it was and the toast shows for 5 s.
  • Keyboard drag: Enter on the handle starts it, arrow keys move between drop places, Enter drops and Escape cancels, with React Aria’s screen-reader announcements. Nothing on screen describes the keys, since R1 shows no shortcut hints.
  • Phone: dragging is off, so there are no handles, and the ⋯ menu lists the statuses directly under a “Move to” label because a side submenu doesn’t fit. The board scrolls sideways, one column at a time. The sidebar isn’t shown; phone navigation is still open.
  • New issue dialog: Cancel and Escape close it without saving. On success it goes to the new issue’s page, such as WEB-43 in In Review.
  • Long Backlog frame: the count shows 300; the frame renders the first 30 cards.

Missing from the kit (confirmed)

I can’t change the kit project from here, so these frames use existing kit classes as stand-ins. Each one should go into the kit before build:

  1. BoardCard is a single button. Needs a container with a title link as the open target, plus handle and ⋯ slots. Stand-in: tl-board-card on a div, quiet icon buttons at 20px, and a stretched title link.
  2. BoardColumn head has no action slot. Stand-in: a quiet 22px icon button after the count.
  3. Pop has no submenu: no caret item, no open-submenu state, no placement. Stand-in: a second Pop beside the first, with tint-2 on the item that opened it.
  4. No line clamp on the card title. Stand-in: an inline 2-line clamp.
  5. BoardColumn body has no overflow or fixed height. Stand-in: flex 1 with overflow-y auto. Scrolling near an edge while dragging is behaviour, not drawn.
  6. No empty-column state, and no “+N” label pill. Stand-ins: a 12px ink-2 line, and the estimate pill (mono on tint-2). I used that over Tag neutral because Tag is taller than the label pills.
  7. Also missing: a keyboard-drag state for the handle and drop zone, Pop items at 44px for touch, a toast with no dismiss and a 5 s timeout, a loading indicator, and phone navigation for the shell.
