Notes and gaps

  • Missing: label colour tokens. The kit has only neutral, clay and terracotta ramps, so there are no AA background/text pairs for Red, Orange, Yellow, Green, Blue, Purple or Pink (tech design §6.6). Every label is drawn as the label Pill in neutral-800 until the eight pairs are added; the colour name is shown beside each label so the frames still read, and it stays useful as a non-colour cue once tokens exist.
  • Missing: a colour swatch for PopItem. The colour menu lists names only for the same reason.
  • Missing: a toast without dismiss and with a 5 s timeout, and a loading indicator. Same gaps as earlier screens.
  • Sort is by name ignoring capitals, so “Safari” sits between frontend and the end of the list. Names are trimmed before the length and duplicate checks.
  • New labels default to Gray. “Choose a color” only comes back from the server (the menu can’t pick anything else); it would show under Color the same way as the name errors.
  • Keyboard: New label focuses Name; Tab reaches Color, Create label, Cancel; Enter submits; Escape cancels and returns focus to New label. Rename puts focus in the field with the text selected; Enter saves, Escape cancels and returns focus to Rename. Change color opens the menu with focus on the current colour; arrow keys move, Enter picks and saves, Escape closes. In the delete dialog focus starts on Cancel and Escape equals Cancel.
  • Deleting a label with no issues still asks: “Delete docs? It will be removed from 0 issues.”
  • After a server toast the form stays open with the text kept. On “That label no longer exists” the list reloads on close; on “This project is archived” the page reloads into the archived view.
  • Any member can manage labels, so the member view matches the admin view apart from the gear.
